### 主要改动一览

- **部署**（新目录 `deploy/`）
  - Compose 项目 `ticketflow`：PostgreSQL（pgvector pg17）、Redis、DRF Web（ASGI）/ Worker / Beat 共用后端镜像、FastAPI、Nginx 网关；
    一次性 `init` 执行 `migrate` 与 `load_init_json`，跑完才放行 DRF。三个命名卷，只有网关发布 `127.0.0.1:8080`。
  - 网关：`/api/`、受鉴权 `/media/` → DRF；`/ws/` → DRF ASGI（只在该 location 设 Upgrade 头）；`/ai/` → FastAPI（HTTP/1.1、不缓冲、不 gzip）；
    `/` 静态文件与 SPA 回退；`ai-context` 与 `/api-docs` 返回 404；三项安全响应头。
  - 密钥只在 Git 忽略的 `deploy/.env`（`python deploy/local.py env` 随机生成，已存在不覆盖）；演示数据 `deploy/seed.sh` / `local.py seed`，
    口令只写 `deploy/.accounts.local.json`。前端镜像依赖层单独缓存。
- **后端为部署做的最小改动**
  - JWT 时钟容差 `JWT_LEEWAY_SECONDS`：DRF 与 FastAPI 共用，独立运行默认 0，交付栈 30 秒；撤销键 TTL 相应延长。
  - 登录限流 `LOGIN_THROTTLE_RATE`：演示栈 1000/h，生产 50/h。
  - 缓存装饰器的 Redis 锁在计算成功后释放失败（`LockNotOwnedError`）只记告警，不再让字段权限装载变成 403；计算失败仍 fail-closed。
- **验收与压测**（新目录 `tests/`，独立 `pyproject.toml` + `uv.lock`）
  - `tests/test_gateway.py`、`tests/test_ai.py`：黑盒验收；新增工作流 `Gateway test project` 只跑锁校验与 Ruff。
  - `tests/load/`：Locust 场景、隔离压测栈（`ticketflow-load`，`:18080`）、5,000 张工单的可重复种子、SQL 与断开探针。
- **前端**（`frontend/`）
  - `playwright.ticketflow.config.ts`（无 webServer，`TF_E2E_BASE_URL` 默认网关）、`e2e/ticketflow/*.tf.ts`、`test:e2e:ticketflow` 脚本。
- **文档**：根目录 README、本文件；压测报告由 Codex 编写。
