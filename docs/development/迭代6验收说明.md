## 4. 验收建议路径（交付栈 http://127.0.0.1:8080）

1. `tf_requester`（普通员工）：首页“AI 助手”提问 → 评价回答 → “转人工提单”确认 AI 预填内容并提交；新建一张“网络”类工单，看到派给网络支持组。
2. `tf_agent` / `tf_agent_other`（技术员）：只看到自己处理与历史处理的工单；处理工单、尝试“退回”；工单详情“查看 AI 对话”；“我的评价”。
3. `tf_requester`：确认解决工单时弹出评价。
4. `tf_admin`（管理员）：全部工单与待分配、改派；评价统计；AI 反馈；账号管理；技能组与分类路由；知识库。

## 5. 已知事项（不阻断）

- 本机 Docker 虚拟机墙钟会来回跳约 12 秒，偶发 401 或 Redis 短 TTL 用例失败；CI 无此问题。重启 Docker Desktop 可缓解。
- 迁移不会补派升级前已存在的未指派开放工单（交付栈约 12 张，在“待分配”里手动指派）。
- 本机全量后端测试仍有既有的验证码规则种子与 Celery 结果读取相关失败（基线同样存在，CI 通过）。
- 演示库里留有若干“冒烟”工单、会话与评价，来自测试，可忽略。
